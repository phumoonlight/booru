Read posts are kept here, in the extension's own storage, so they survive a board's site data being cleared and so every board can be exported as one file.

Read posts

Board Posts Stored Read up to

Read up to is a post number: everything at or below it counts as read without being stored, and the numbers already held inside it are deleted. It is what makes the database smaller — a board sourced from for a year is mostly old posts you will never look at again, and one number says so where thousands of them did. The range is a blanket, so a post under it cannot be unmarked, and clearing the number does not bring back what it deleted. Empty for none.

Marking

Off, nothing is faded and nothing is recorded — the boards are drawn as they come. Nothing already stored is lost.

Import and export

The file is plain JSON: a sorted list of post numbers per board and nothing else.
