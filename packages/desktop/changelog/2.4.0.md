# 2.4.0

### Added

- **📚 Tag catalogs.** A named set of tags — an artist and their series, the three meta
  tags you always use — applied to a post in one press. Build them on the Tags screen:
  ➕ New names one, then 👆 Choose from the list ticks tags into it from the grid below,
  the same gesture the tag rules use.
- **A catalog can be built from a post.** 📋 From a post inside an open catalog is the
  import dialog the queue already had: find something you tagged an hour ago and its tags
  become the set, instead of picking the same twelve again.
- **📚 Catalogs sits on every tag field** — each queue card, Apply to all, and the post
  editor — so a catalog applies to a post you are about to make and one already on the
  board alike. Each row says how many tags it would actually add, and a catalog with
  nothing left to give is ticked rather than pressable.
- **Catalogs travel with your settings.** They are a third section of `save.json`, so
  Export and Import carry them like the tag rules.

### Changed

- **The Tags screen's panels take turns.** Opening Catalogs closes an open tag and vice
  versa — both pin to the top of the list, and only one of them can be the thing the grid
  below is answering.

A catalog holds tag names and nothing else — no rating, no category. What a tag is filed
under is read off the board when the catalog is applied, so recategorizing a tag can never
leave a stale copy behind, and a catalog naming a tag that has since been deleted quietly
adds nothing rather than coining it again.
