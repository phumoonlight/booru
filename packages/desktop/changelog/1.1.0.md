# 1.1.0 — 2026-09-04

### Added

- Tag rules, a screen beside Tags, holding two kinds of rule.
- **Implications** like `white_bra → bra`, so the broad tag stops being the one you
  forget. What they imply is listed under the tag box and goes up with the post.
- **Recommendations** like `panties → black_panties bow_panties`: the tags that usually
  go together, offered under the box as chips to press. Nothing is added until you press
  one.
- An implication can raise the rating too: `panties → E2` lifts an image rated lower and
  leaves a higher one alone, so a rating you set by hand is never talked back down.
- Both are kept in `save.json` on this machine. Nothing about them is uploaded.
- Tag autocomplete is served from a copy of the board's tag list kept for a day, so typing
  a tag no longer asks the server on every keystroke. It refreshes on its own, is dropped
  whenever an upload finishes, and Settings has a Clear cache button if it ever looks wrong.

### Fixed

- Backspace in the tag box no longer eats the tag before the cursor.
