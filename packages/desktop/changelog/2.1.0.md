# 2.1.0

Tags are chosen by category now, on both screens that carry them.

### Changed

- **The picture is across the top**, the way a queue card carries it, with the size,
  format and file size under it. It used to sit in a 192px column beside the form — not
  enough of an image to decide a rating by.
- **There is no Save button.** Adding a tag, removing one, changing the rating or
  committing a source each write to the board on the spot; the line beside the post
  number says `saving…` and then `saved`. A write that fails puts the old value back and
  says why.
- **Tags are grouped by category**, as the website's post page draws them. Every category
  gets a row — the empty ones too, since their ＋ is the only way to put a first tag in
  them — and each tag carries its own ✕.
- **＋ offers that category's tags and nothing else.** Filter by substring, click to add.
  It stays open across picks — tagging happens in runs — and each pick clears the filter
  and gives the box back the cursor.
- **The rating scale is coloured** on every screen that offers it — the post editor, each
  queue card and the Apply-to-all bar — in the menu and in the field, the same four colours
  the board uses.
- **The source is read until you click it**, then an input; Enter or clicking away saves
  it, Escape abandons the edit.
- **Delete asks in a red panel** that names the post and says what goes with it — the row,
  the image, the thumbnail, every link — and the button that does it is filled red.

- **The upload queue uses the same editor**, per card and on the Apply-to-all bar. Tag
  rules still work exactly as they did: implied tags are listed under the rows and go up
  with the post, a rule can still lift a card's rating, and recommendations are still
  chips you press.
- **Recommendations also work on the post editor** now, where a press commits like every
  other control there. Implied tags are not shown on that screen — they are only ever
  appended at upload, so a line of tags that were not being written would be misleading.

- **A finished upload shows the tags the post came out with**, read back from the board,
  and offers **Review tags** — one click into that post's editor. That moment is when
  tagging is worth checking; ten uploads later, finding the post again is a search.

### Removed

- The free-text tag box. Typing a name gave it no category until the board was asked, so
  a new tag was coined as General whatever it actually was. The Tag rules screen still has
  the box, since what is typed there is a rule rather than a post's tag.
- **Creating a tag while tagging.** The pickers offer only what the board already has.
  A tag named in a hurry, by someone looking at a picture rather than at the vocabulary,
  is how a board ends up with `twintail`, `twintails` and `twin_tails` — so naming one is
  the Tags screen's job, where the whole list is in front of you.
