# 2.2.0

## Added

- **Links open in a browser you pick.** Settings lists the browsers installed on this
  machine; pick one and every post, tag and Open site goes there.
- **Import tags from a post**, on every queue card: search the board, pick a post, its
  tags are added to the card.
- **ℹ️ About rating** on the upload screen: what the four tiers mean, with examples, and
  what choosing one does to a post on the board.
- **Fold a queue card away** with the ▾ beside its number. Folded, it still says its size,
  tag count and rating.
- **Mark a queue card done** with the ☐ beside the bin — a tick for your own tracking,
  nothing more.
- **‹ › beside the post number**, and ← → on the keyboard: step through the posts a search
  found without going back to the grid. Past the last one read, it reads the next chunk.
- **🔄 Refresh in Browse**, top right, with the time of the last read beside it.

## Changed

- **Browse keeps what it was showing.** Coming back from another screen paints the same
  grid, Load more chunks included, instead of searching again and re-fetching every
  thumbnail.
- **Duplicates are caught when a file is staged**, not when it is uploaded. That row shows
  a notice and a way to the existing post instead of a tag form. Two copies of one image
  in the same queue are caught too.
- **Apply to all starts folded**, and its heading says what is waiting inside it.
- **Removing a queue card asks first** if tags or a source were typed into it.
- Tags has the same labelled Refresh as Browse, in place of its bare 🔄.

## Fixed

- A category with enough tags to wrap wrapped underneath its own label.
