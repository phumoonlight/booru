# 2.0.1

### Changed

- Saving a post in Browse stays on the post. It used to drop back to the grid, which
  read as the post having been closed rather than written — and a rating set one option
  wrong meant hunting for the card again. Save now says **Saved** and leaves the post in
  front of you; **← Back** is the way out, and the grid re-reads on the way.

### Fixed

- Deleting still returns to the grid, since there is no longer a post to look at.
