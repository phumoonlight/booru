# 1.0.0 — 2026-08-30

First installable release. Everything before this was the app being built in the repo;
there was no version worth naming until it could be handed to someone.

- The website's upload page as a Windows app: drag images in, tag them, upload. The
  pipeline, the post write path, the tag queries and both AVIF encoders are compiled
  out of the web's `src/`, so a post made here is a post made there.
- Files may be **50MB and 100MP** — the web's 4MB / 20MP ceilings are Vercel's function
  limits, and nothing here is on a clock.
- Setup is four typed-in values on a settings screen: project URL, anon key, service
  role key, and the board's address. The app reads no environment, so a checkout and an
  installed copy meet the same screen.
- Settings, session and credentials live in one readable `save.json` in the app's data
  folder — plain text, service role key included. Treat the folder as the secret.
- Three screens — upload, settings, about — with the queue hidden rather than unmounted
  when it is not in front, so glancing at About never costs a staged upload.
- Signing out is local: logging out of the uploader leaves the browser signed in.
- Installs as **Pubooru**, with an icon, and offers to delete the settings folder when
  uninstalled.
