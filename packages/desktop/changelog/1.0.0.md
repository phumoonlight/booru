# 1.0.0 — 2026-08-30

First installable release.

### Added

- The website's upload page as a Windows app — same pipeline, write path and AVIF
  encoders, compiled out of the web's `src/`.
- Files up to 50MB and 100MP, against the web's 4MB and 20MP.
- Setup screen for the four connection values; no environment is read.
- Settings, session and credentials in one readable `save.json`. Plain text, service
  role key included — treat the folder as the secret.
- Upload, settings and about screens; the queue is hidden, not unmounted, behind the
  other two.
- Local sign-out, so logging out here leaves the browser signed in.
- Installs as Pubooru, with an icon, and offers to delete its settings on uninstall.
