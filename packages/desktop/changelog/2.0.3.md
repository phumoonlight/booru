# 2.0.3

### Added

- Six categories, each with a colour of its own: **Body**, **Color**, **Clothes**,
  **Exposure**, **Posture** and **Sexual**. They sit between Character and General on the
  Tags screen, on the tag field's chips and on the website's tag pages.

### Changed

- The category field is a menu again. Free text let a category be coined that had no
  colour and no place in the order, which is a tag nobody can find; adding one is a line
  in the shared list instead, and it then exists everywhere at once.
