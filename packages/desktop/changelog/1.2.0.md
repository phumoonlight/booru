# 1.2.0

The board no longer has accounts, and this app is now the only thing that can change it.

### Added

- **Browse** — search the board with the same query grammar the website uses
  (`1girl -solo rating:explicit`), then click a post to edit its rating, source and tags,
  or delete it along with both of its stored images.
- **Tag management on the Tags screen** — click a tag to rename it, change its category
  or delete it; New tag names one up front, and Apply by tag adds one tag to every post
  already carrying another.

### Changed

- **No login.** The app opens straight on the upload queue. Which board it talks to was
  already decided when the build was made; now the only thing standing in front of it is
  having the app.
- The rating scale is General, Sensitive, Questionable, Explicit. Searching for one is
  still `rating:explicit`, spelled out.
- `save.json` no longer holds a session token or a remembered password. Both are deleted
  from an upgraded copy on first launch.
