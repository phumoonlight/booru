# 1.0.4 — 2026-09-01

### Changed

- No setup screen: the board is set when the app is built, so it opens on the login form.
  Settings shows which board, and the stored keys are deleted.
- Uploads run at below-normal priority, so they no longer stall anything else.
- The Tags screen remembers its list; 🔄 by the title re-reads it.
- "Connection settings" in the header is now "Settings".

### Added

- **Posts** in the header, opening the board's gallery in your browser.
- **Compression** settings: encoder threads (half the cores by default) and priority.
  Same quality either way, only slower.

### Fixed

- Tags are coloured by category again, matching the website.
