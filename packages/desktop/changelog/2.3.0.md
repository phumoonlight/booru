# 2.3.0

### Added

- **🗺️ Rule map**, top right of the Tags screen: every rule on this machine at once, with
  implications drawn as the chains they make. Read-only; Escape closes it.
- **A filter box on the Tags screen**, taking `blue archive` or `blue_archive`.
- **Export and import settings.** Two buttons write `save.json` to a file you choose and
  read it back. An import takes only the sections the file has and takes effect at once.
- **Reach a post by number.** The `Post #15` heading in the editor is a box: type a
  number, press Enter, and you are there. Escape puts the old one back.
- **Browse draws two ways.** 🔳 Grid is the even columns it always was; 📐 Ratio gives
  every thumbnail the same height and its own width, nothing cropped.
- **The search box completes tags.** Up to five names appear as you type a word, with
  their category colour and post count; ↑ ↓ and Enter pick one, Escape hides them. It
  completes the word you are on, so `-sol` finds `solo` and the rest of the query is left
  alone.
- **Browse opens where you left it.** The last search and the posts it found are kept for
  a day. 🔄 Refresh reads the board again; so does an upload, by itself.
- **Thumbnails are kept on disk**, so a grid you have seen before paints immediately.
  They never go stale — a thumbnail's name is a fingerprint of the image itself.
- **A tag's mark can be a colour.** The box in front of a tag's name takes an emoji as
  before, or a `#hex` or a name like `blue`, which is drawn as a dot. One per tag.
- **About says when it is a development build**, which an installed copy never is.

### Changed

- **Tag rules live on the tag.** The Tag rules screen is gone; click a tag on the Tags
  screen and its implications and recommendations are on the same panel as its name.
- **Rules are picked from the grid, not typed.** 👆 Choose turns the tag list into a
  picker — click to tick a tag into the rule, ✅ Done or Escape to stop. A rule can no
  longer name a tag that does not exist; make it with ➕ New tag first, on the same screen.
- **The tag categories are re-cut.** `head`, `exposure` and `posture` are gone, `sexual`
  is now `nsfw`, and `appearance`, `accessories` and `action` have arrived. Nothing is
  migrated: a tag under an old name still works, but is drawn plain and sorted last, which
  is how you find the ones left to move.
- **The automatic colour dot is gone.** It read `golden_retriever` as gold and could not
  be corrected. Set the mark on the tag instead, and it is right everywhere.
- **Small images are compressed far less.** The post image's AVIF quality now slides with
  its longer side: 50 at 1920px and above, climbing to 100 at 1280px and below. Nothing
  gets bigger — an AVIF is still only stored when it beats the file you uploaded.
- **Tags and Browse have a toolbar.** 🔄 Refresh leads the row and the box beside it runs
  to the edge of the window. New tag, Apply by tag and Rule map moved to the title line.
- **A tag's posts open in this window.** 🖼️ On the board is now 🔍 Its posts, going to
  Browse with the tag searched — the same question, answered where you can fix what it
  finds.
- **Back leads the editor's header**, with ◀️ ▶️ beside it, where it used to trail them.
- **Buttons are drawn one way**, everywhere: an emoji, its words, no box, and a soft
  background under the pointer instead of an underline. Real links keep theirs.

### Fixed

- **A header item you are already on stays there.** Pressing Browse while on Browse used
  to drop you back on the queue.
- **ℹ️ About rating stays at the top** of the upload screen instead of floating in the
  middle of an empty queue.

Your rules are untouched — same `save.json`, same two sections. Only where you edit them
moved.
